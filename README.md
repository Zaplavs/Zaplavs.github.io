# Портфолио Александра Заплавного

Готовый адаптивный сайт на HTML, CSS и JavaScript. Vite собирает четыре страницы в папку `dist`. Серверная часть и ключи API для работы сайта не нужны.

## Что сделано

- Главная страница: предложение, проекты, услуги, фотография, этапы работы, FAQ и контактный блок.
- Три самостоятельные страницы концепций: Forma, Крошка и Тише.
- Основная тема — нейтральный графитовый фон. Переключатель светлой темы находится в шапке каждой страницы. Выбор сохраняется в браузере.
- Вся карточка проекта кликабельна; указатель перехода расположен рядом с названием.
- Все обращения направляются Александру: `https://t.me/evgeinif`.
- Стоимость обсуждается индивидуально. Выдуманные клиенты, отзывы, опыт и коммерческие результаты не указаны.
- Фотография и все изображения и шрифты хранятся локально.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite, обычно `http://127.0.0.1:5173`.

## Сборка и публикация

```sh
npm run build
npm run preview
```

Предпросмотр сборки: `http://127.0.0.1:4179`.

Для публикации загрузите **содержимое** `dist` в корень статического хостинга. Сайт настроен для отдельного домена или корня поддомена. В `dist` уже включены три страницы проектов и все ресурсы. Публикация во время разработки не выполнялась.

## Проверки

После сборки запустите `npm run preview`, затем в другом терминале:

```sh
npm test
```

Проверки используют установленный Google Chrome через Playwright. Можно переопределить адрес сервера переменной `TEST_URL`.

Проверяются четыре страницы, обе темы, ширины 320 / 390 / 768 / 1440 px, загрузка фотографий, отсутствие ошибок JavaScript и пропавших ресурсов, меню, FAQ, якоря, адреса Telegram, сохранение темы и автоматические правила доступности WCAG A/AA. Отчёт и снимки экранов сохраняются в `test-results`. Автоматическая проверка не заменяет полную ручную экспертизу доступности.

## Где менять содержимое

| Файл | Содержимое |
| --- | --- |
| `index.html` | Главная страница и личные данные |
| `projects/*.html` | Страницы концепций |
| `src/style.css` | Основная сетка и адаптивная вёрстка |
| `src/project.css` | Визуальные концепции сайтов |
| `src/themes.css` | Светлая и графитовая темы, переключатель |
| `src/main.js` | Тема, меню и анимации появления |
| `public/assets/profile-source.jpg` | Фотография Александра |
