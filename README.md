# Портфолио Александра Заплавного

Готовый адаптивный сайт на HTML, CSS и JavaScript. Vite собирает одну страницу в папку `dist`. Серверная часть и ключи API для работы сайта не нужны.

## Что сделано

- Главная страница: предложение, проекты, цифры, услуги, слайдер «было / стало», фотография, этапы работы, стоимость, FAQ и контактный блок.
- Блок работ: пять реальных сайтов (Тунец, Lotus Vie, Империя, Рыжая кошка, Лавли) — превью главных экранов без ссылок. По клику открывается снимок всей страницы. Шестая карточка сетки приглашает обсудить свой проект.
- Основная тема — нейтральный графитовый фон. Переключатель светлой темы находится в шапке каждой страницы. Выбор сохраняется в браузере.
- Вся карточка проекта кликабельна; указатель перехода расположен рядом с названием.
- Все обращения направляются Александру: `https://t.me/evgeinif`.
- Стоимость обсуждается индивидуально. Выдуманные клиенты, отзывы, опыт и коммерческие результаты не указаны.
- Фотография и все изображения и шрифты хранятся локально.
- Разметка Schema.org, `robots.txt`, `sitemap.xml` и обложка для соцсетей `public/assets/og-cover.png`.

## Интерактивные элементы

| Элемент | Что делает |
| --- | --- |
| Слайдер «как обычно / моя работа» | Три сферы на вкладках — автосервис, салон красоты, спа. Слева собирательный устаревший макет, справа скриншот реальной работы; работает мышью, пальцем и стрелками. Под каждым — разбор трёх изменений |
| Просмотр работы | Клик по превью открывает снимок всей страницы: прокрутка, листание стрелками, Escape |
| Палитра команд | `Ctrl` / `⌘` + `K` или кнопка в подвале: переход по разделам и кейсам, смена темы и акцента, Telegram. Поиск нечёткий — «стим» находит «Стоимость» |
| Акцентный цвет | Четыре варианта в подвале, выбор сохраняется в браузере |
| Курсор-компаньон | Кольцо за курсором с подсказкой на карточках и кнопках. Только для мыши |
| Прелоадер | Показывается один раз за вкладку |
| Прочее | Прогресс чтения, точечная навигация по разделам, счётчики, бегущая строка, появление заголовков по словам, наклон карточек, магнитные кнопки, параллакс первого экрана, кнопка «наверх» |

Весь слой выключается при системной настройке «уменьшить движение» и не использует внешних библиотек.

### Где менять цену

Стартовая цена названа прямо и повторяется в трёх местах `index.html` — держите их согласованными:

1. Блок `06 / СТОИМОСТЬ` — крупная цифра в `.price-figure`.
2. Строка под услугами — `.price-note`.
3. Первый ответ в FAQ «Сколько стоит сайт?».

Тест `npm test` проверяет, что во всех трёх местах стоит одно число. Отдельно посмотрите обещание «Ответ в Telegram за 24 ч» в блоке цифр на главной.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite, обычно `http://127.0.0.1:5173`.

## Сборка и публикация

```sh
npm run build
npm run preview
```

Предпросмотр сборки: `http://127.0.0.1:4179`.

Для публикации загрузите **содержимое** `dist` в корень статического хостинга. Сайт настроен для отдельного домена или корня поддомена. В `dist` уже включены три страницы проектов и все ресурсы. Публикация во время разработки не выполнялась.

## Проверки

После сборки запустите `npm run preview`, затем в другом терминале:

```sh
npm test
```

Проверки используют установленный Google Chrome через Playwright. Можно переопределить адрес сервера переменной `TEST_URL`.

Проверяются главная страница, обе темы, ширины 320 / 390 / 768 / 1440 px, загрузка фотографий, отсутствие ошибок JavaScript и пропавших ресурсов, меню, FAQ, якоря, адреса Telegram, сохранение темы, автоматические правила доступности WCAG A/AA и интерактивный слой: согласованность цены между секциями, слайдер сравнения с клавиатуры, палитра команд, сохранение акцента, бегущая строка без разрывов на четырёх ширинах, состав сетки работ, просмотр работы целиком и вкладки сравнения. Отчёт и снимки экранов сохраняются в `test-results`. Автоматическая проверка не заменяет полную ручную экспертизу доступности.
